# Netflix-Content-Explorer
This project is about data analytics ,with help of dataset to answer questions like movies V/S TV shows and many more.
Using Python,Numpy ,Pandas,Matplotlib and Seaborn to analyze dataset and answer questions :
1. How has the number of titles added changed over decades?
2.  Movies vs TV Shows — what’s the split?
3.  Top 10 genres.
4.  Top 10 countries producing content.
5.   Distribution of movies and TV shows - Duration and Seasons.

# Dataset
The dataset used is :
 [https://www.kaggle.com/datasets/shivamb/netflix-shows](https://www.kaggle.com/datasets/shivamb/netflix-shows)
This data set had empty cell which were filled with "Unknown" and the release date column is in irregular format was corrected with help of pandas datetime function.


# Visulizations
The above question were answered with the help of plots created using Seaborn :
1. Barplot
2. Histogram
3. Piechart

# Key Finding
- The catalog is 69.6% movies, 30.4% TV shows (6,131 vs 2,676 titles)
- Content additions peaked in 2019 (1,999 titles)
- The United States produces the most content (2,818 titles), followed by India (972) and the UK (419)
- Movie runtimes cluster around 90–100 minutes; most TV shows run for just 1 season
